# Nator Inc. — especificación de producción

## Sistema visual

- Base: `#F7FAFC`; superficies: `#FFFFFF`; texto: `#0F1724`; texto secundario: `#6B7280`.
- Acción: `#D6362D`; acción hover: `#B32B24`; acento suave: `#FEECEB`.
- Tipografía: Inter, con fallback Roboto/sans-serif. Títulos 40–64 px desktop, 34–48 px tablet, 34–42 px mobile; cuerpo 16–18 px.
- Radios: 4–8 px. Sombras discretas. Iconografía Lucide lineal, 1.8–2 px de trazo.

## Componentes

- Botón primario: fondo rojo, texto blanco, altura 48–52 px, icono de flecha; hover rojo oscuro.
- Botón secundario: fondo transparente, borde gris, texto oscuro; hover con superficie blanca.
- Cards: fondo blanco, borde suave, radio 8 px; título, descripción y acción claramente jerarquizados.
- Formulario: labels persistentes, controles de 48 px, focus visible rojo, mensajes de error junto al campo.
- CTA A: “Solicitar demo”. CTA B: “Agendar demo gratuito”.

## Variantes responsivas

- Mobile 320–767: una columna, navegación desplegable, tarjetas apiladas, controles táctiles de al menos 44 px.
- Tablet 768–1023: composición en dos columnas cuando hay espacio; servicios en dos columnas.
- Desktop 1024–1439: contenedor de 1180 px, hero dividido 50/50, grids de tres columnas.
- Wide 1440+: contenedor máximo de 1240 px; escala tipográfica estable, sin estirar el contenido.

## Copia final

La copia incluida en la interfaz es la versión final en español para hero, servicios, métricas, proceso, tecnologías, casos, planes, formulario y footer. Las métricas y testimonios están identificados como referencias hasta recibir datos reales.

## Assets para producción

Pendientes de solicitar al equipo:

1. Logotipo oficial de Nator Inc. en SVG (incluyendo versión monocroma).
2. Capturas reales de dashboards y demostraciones en WebP (1x/2x).
3. Tres testimonios aprobados: texto, nombre, cargo, compañía y autorización de uso.
4. Favicon y app icons oficiales.
5. SVG oficiales de UiPath, n8n, Zapier y Glassio Agents con permiso de marca.
6. Correos, enlaces sociales, URL de privacidad y dominio definitivos.

Los símbolos tipográficos actuales para tecnologías son placeholders accesibles. Los iconos de interfaz son SVG generados por Lucide y se entregan optimizados en el bundle.
